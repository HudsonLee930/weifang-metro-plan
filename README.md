---

## 项目简介

潍坊是山东省重要的制造业城市和农业强市，市域人口近千万，经济总量位居全省前列。然而，受限于现行轨道交通审批门槛和区域交通格局，潍坊主城区至今未通轨道交通。

本项目试图回答一个问题：

> **如果潍坊有轨道交通，线网应该长什么样？**

基于对城市结构、客流走廊、枢纽布局和区域发展战略的分析，本项目提出了一套远期线网规划草案，包含市区普线、市域快线和预留环线，供关心潍坊城市发展的朋友讨论、批评和迭代。

## 设计原则

1. **核心区加密，外围拉开站距**，平衡覆盖与速度。
2. **市域快线与城区普线在枢纽站换乘**，实现功能分离。
3. **2号线与S2号线贯通运营**，避免“90度转弯”的结构硬伤。
4. **4号线填补卧龙街—动力路横向走廊**，完善北部东西向覆盖。
5. **站点命名以“地名+功能”为原则**，兼顾历史地标与现势地名。
6. **线网预留弹性**，8号线为远期环线预留接口，S3号线向南通往安丘。
